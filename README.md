# SAKK EXTERNAL

هذا هو المشروع الكامل المرسل في أرشيف MediaFire، ويحتوي على مشروع Xcode الأصلي والواجهات والخدمات والأصول.

## البنية

- `ThreeOneOSFive/views`: واجهات التطبيق ونظام التصميم.
- `ThreeOneOSFive/helpers`: خدمات الملفات والمشاريع والتفعيل والمزامنة.
- `ThreeOneOSFive/Assets.xcassets`: الأيقونات والصور والخلفيات.
- `ThreeOneOSFive/Patches`: حزم patch المحلية.
- `ThreeOneOSFive/exploit` و`ThreeOneOSFive/kexploit`: ملفات الدعم الأصلية للمشروع.
- `ThreeOneOSFive.xcodeproj`: مشروع Xcode.
- `build_unsigned.sh`: بناء IPA غير موقّع على macOS.

## أمان التفعيل

التطبيق يرسل تحقق M3SB مباشرةً من iOS، ثم يرسل رد M3SB الموقّع إلى VesperDash ليصدر الخادم جلسة قصيرة العمر لتنزيل الكتالوج والحزم. الـPackage Token وHMAC Secret يُحقنان وقت البناء من GitHub Actions secrets ويُخزنان بصيغة XOR/Base64 مموهة داخل IPA.

**التمويه ليس تشفيرًا آمنًا:** يمكن استخراج القيم من IPA. اختير هذا المسار بعد أن كان طلب VPS إلى M3SB يُرفض بـ403، مع قبول المستخدم لمخاطرة استخراج الأسرار. لا تضع القيم في المصدر أو المحادثات، ودوّرها إذا أردت إلغاء صلاحية نسخ IPA القديمة.

راجع [`vesperdash/README.md`](vesperdash/README.md) لمسار إصدار جلسة VesperDash ونشر الخادم مع أو بدون تدوير القيم.

## البناء

يتطلب بناء IPA جهاز macOS مع Xcode. يتطلب `build_unsigned.sh` المتغيرين `M3SB_PACKAGE_TOKEN` و`M3SB_HMAC_SECRET` في بيئة البناء؛ لا يطبع السكربت القيم. شغّل:

```bash
./build_unsigned.sh
```

أو استخدم GitHub Actions عبر `.github/workflows/build.yml` بعد ضبط الاسمين أعلاه كـGitHub Actions secrets. ينتج البناء ملفًا غير موقّع باسم `SAKK-EXTERNAL-Build-46-unsigned.ipa` ويتحقق من غياب النص الخام للقيم داخل التطبيق.

يبقى ملف executable باسم `SAK` بحشو 690MB كما هو؛ لم يُقلص أو يُستبدل. التحسينات لتقليل IPA تقتصر على الأصول والموارد الأخرى.

في Build 46، تُحفظ الحزم المستوردة ومساحات عملها داخل `Library/Application Support/.7c91e4a2/.p` و`.w` بحماية ملفات iOS، وتُنقل النسخ القديمة تلقائيًا. أما الحزم البعيدة، فتُنزل عند أول ضغط على `INJECT`، ويُتحقق من SHA-256 ثم تُحفظ جميعها داخل **ملف cache واحد مشفّر بـAES-GCM** في `.7c91e4a2/.v/.cache` بمفتاح محفوظ في Keychain؛ ولا يبقى أي ملف `.3105` منفصل بعد انتهاء التنزيل. عند Inject لاحقًا تُقرأ الحزمة من هذا المخزن وتُفك للذاكرة، ويُعاد تنزيلها فقط إذا تغيّر SHA-256 أو لم يعد الملف موجودًا. هذا بديل آمن عن تعديل executable الموقّع، والذي لا يسمح به iOS بعد التثبيت. لا يمنع هذا المخزن استخراج البيانات على جهاز مكسور الحماية أو بعد سرقة مفتاح Keychain. يُخفى عنوان ومسار التحقق داخل التطبيق بصيغة بايتات مموهة، مع فحص يمنع ظهورهما كنص واضح داخل IPA؛ هذا تمويه لنتائج البحث البسيطة وليس تشفيرًا غير قابل للعكس. زر `INJECT` صغير مستطيل بزوايا دائرية وخطه مثل أسماء الوظائف، بلا أيقونة تنزيل أو شريط `INJECT STATUS`؛ وعند OFF يظهر `RESTORING…` مع مسح ضوئي ناعم في الخلفية. يحتفظ التطبيق بنسخة الاستعادة الضرورية حتى OFF.
