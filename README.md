# VESPER

هذا هو المشروع الكامل المرسل في أرشيف MediaFire، ويحتوي على مشروع Xcode الأصلي والواجهات والخدمات والأصول.

## البنية

- `ThreeOneOSFive/views`: واجهات التطبيق ونظام التصميم.
- `ThreeOneOSFive/helpers`: خدمات الملفات والمشاريع والتفعيل والمزامنة.
- `ThreeOneOSFive/Assets.xcassets`: الأيقونات والصور والخلفيات.
- `ThreeOneOSFive/Patches`: حزم patch المحلية.
- `ThreeOneOSFive/exploit` و`ThreeOneOSFive/kexploit`: ملفات الدعم الأصلية للمشروع.
- `ThreeOneOSFive.xcodeproj`: مشروع Xcode.
- `build_unsigned.sh`: بناء IPA غير موقّع على macOS.

## أمان التفعيل

التطبيق يرسل تحقق M3SB مباشرةً من iOS، ثم يرسل رد M3SB الموقّع إلى VesperDash ليصدر الخادم جلسة قصيرة العمر لتنزيل الكتالوج والحزم. الـPackage Token وHMAC Secret يُحقنان وقت البناء من GitHub Actions secrets ويُخزنان بصيغة XOR/Base64 مموهة داخل IPA.

**التمويه ليس تشفيرًا آمنًا:** يمكن استخراج القيم من IPA. اختير هذا المسار بعد أن كان طلب VPS إلى M3SB يُرفض بـ403، مع قبول المستخدم لمخاطرة استخراج الأسرار. لا تضع القيم في المصدر أو المحادثات، ودوّرها إذا أردت إلغاء صلاحية نسخ IPA القديمة.

راجع [`vesperdash/README.md`](vesperdash/README.md) لمسار إصدار جلسة VesperDash ونشر الخادم مع أو بدون تدوير القيم.

## البناء

يتطلب بناء IPA جهاز macOS مع Xcode. يتطلب `build_unsigned.sh` المتغيرين `M3SB_PACKAGE_TOKEN` و`M3SB_HMAC_SECRET` في بيئة البناء؛ لا يطبع السكربت القيم. شغّل:

```bash
./build_unsigned.sh
```

أو استخدم GitHub Actions عبر `.github/workflows/build.yml` بعد ضبط الاسمين أعلاه كـGitHub Actions secrets. ينتج البناء ملفًا غير موقّع باسم `VESPER-Build-26-unsigned.ipa` ويتحقق من غياب النص الخام للقيم داخل التطبيق.

في Build 26، تُحفظ حزم `.3105` ومساحات عملها داخل `Library/Application Support/.7c91e4a2/.p` و`.w` بحماية ملفات iOS، وتُنقل النسخ القديمة من `Documents` و`Documents/Patches` و`Application Support/PatchProjects` تلقائيًا مع حل تعارض الأسماء دون حذف البيانات. يُعطّل إظهار مجلد التطبيق في Files/Finder؛ الاستيراد والتصدير من داخل التطبيق يظلان متاحين. يفتح التطبيق مباشرة بينما يُجلب الفهرس وتُنزل الحزم في الخلفية؛ تعرض قائمة كل باتش حالته، ولا يتاح التفعيل قبل تثبيت الحزمة والتحقق منها. تُنزّل حتى أربع حزم بالتوازي. إعدادات Release تزيل رموز التصحيح القياسية. هذه تدابير ترفع كلفة النسخ العادي ولا تمنع استخراج الملفات على جهاز مكسور الحماية أو تحليل كود موجود في IPA. يضيف البناء 690,000,000 بايت من النقاط إلى نهاية الملف التنفيذي، ويضمّن داخله صوتي التفعيل والإلغاء ونسخًا مرجعية من ملفي أيقونة التطبيق. تبقى ملفات الموارد التي يحتاجها iOS في مواقعها المعتادة، ويُحذف الصوتان من الباندل بعد تضمينهما. يفحص إصدار Release عند بدء التشغيل اسم العرض ومجلد/تنفيذي `VESPER` وملفي الأيقونة. عند اكتشاف اختلاف يعرض `Security Alert` بلا أزرار لمدة 3 ثوانٍ ثم ينهي التطبيق؛ لا يمكن تجاوز التنبيه بالدخول. لا يفرض قيمة ثابتة لمعرّف الحزمة، لأن أداة إعادة التوقيع قد تغيّرها تلقائيًا. التغييرات في الملفات الأخرى لا تسبب هذا الإغلاق. قيمة الحشو ثابتة عند 690MB ويُرفض البناء إذا حاول أحد تغييرها. يُضغط IPA بأقصى مستوى ZIP (`-9`)، لكن الحجم المضغوط يعتمد على الملفات ولا يمكن ضمان أنه 2MB. نصوص اللغات تُضمَّن في executable بدل مجلدات `.lproj`؛ هذا تمويه فقط ولا يحمي الأسرار.
