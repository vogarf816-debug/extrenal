# VESPER External — Original Design Backup

This folder preserves the app's UI source and visual assets as they were before the blue SAKK LIVE refresh on 2026-10-26.

Included: app entry and overlays, main tab screens, activation screen, view/design-system source files, and the complete original asset catalog.

These are archival copies only. They intentionally live outside `ThreeOneOSFive/` so Xcode does not compile duplicate Swift source files or bundle old assets.
